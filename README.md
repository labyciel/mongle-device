# 몽글 디바이스 — 올리는 방법 (처음 하는 분용)

서버 시간으로 돌아가는 몬스터 육성 게임이에요. 이 폴더 하나가 **서버 + 게임 화면** 전부예요.
아래 순서대로 하면 `https://○○○.up.railway.app` 같은 주소가 생기고, 친구에게 그 주소만 보내면 같이 할 수 있어요.

준비물: 이메일 주소 하나. 설치할 프로그램은 없어요. (전부 웹사이트에서 해요)

---

## 1단계. GitHub에 코드 올리기 (약 5분)

GitHub는 코드를 보관하는 곳이에요. Railway가 여기서 코드를 가져가요.

1. https://github.com 에서 회원가입 후 로그인해요.
2. 오른쪽 위 **+** 버튼 → **New repository** 를 눌러요.
3. Repository name에 `mongle-device` 라고 쓰고, **Public** 이든 **Private** 이든 상관없어요. **Create repository** 를 눌러요.
4. 다음 화면에서 **uploading an existing file** 링크를 눌러요.
5. 받은 zip 파일의 압축을 풀고, 그 안의 **내용물 전부**(`server.js`, `package.json`, `public` 폴더 등)를 브라우저 창에 끌어다 놓아요.
   - `public` 폴더가 폴더째로 올라가야 해요. 목록에 `public/app.js` 처럼 보이면 성공이에요.
   - 크롬이나 엣지에서는 폴더째 끌어다 놓을 수 있어요.
6. 아래쪽 **Commit changes** 를 눌러요.

## 2단계. Railway에 서버 만들기 (약 5분)

Railway는 서버를 대신 돌려주는 곳이에요.

1. https://railway.com 에서 **GitHub 계정으로 로그인**해요.
2. **New Project** → **Deploy from GitHub repo** → 방금 만든 `mongle-device` 를 골라요.
   - 저장소가 안 보이면 **Configure GitHub App** 을 눌러 Railway가 그 저장소를 볼 수 있게 허락해 주세요.
3. 잠시 기다리면 자동으로 설치하고 실행돼요. 상자(서비스)에 초록색 **Active / Success** 가 뜨면 돼요.

## 3단계. 저장 공간 붙이기 ⚠️ 꼭 해야 해요

이걸 안 하면 **서버가 재시작될 때마다 모든 몬스터와 계정이 사라져요.**

1. 프로젝트 화면의 빈 곳을 **오른쪽 클릭**(또는 `Ctrl+K` / `⌘K`) → **Volume** 을 골라요.
2. 연결할 서비스로 `mongle-device` 를 골라요.
3. **Mount path** 에 `/data` 라고 적어요.
4. 자동으로 다시 배포돼요. 서버가 저장 공간 위치를 알아서 찾으니 다른 설정은 필요 없어요.
   - 확인 방법: 서비스 → **Deployments** → 최신 배포의 **View logs** 에 `데이터 저장 위치: /data` 가 보이면 성공이에요.

## 4단계. 주소 만들기

1. 서비스 상자를 눌러 **Settings** 탭 → **Networking** → **Generate Domain** 을 눌러요.
2. 생긴 주소를 눌러 게임이 뜨면 끝이에요! 이 주소를 친구에게 보내세요.

---

## 알아두면 좋은 것

**비용**: Railway는 처음에 체험 크레딧을 주고, 이후 무료 플랜은 매달 소량의 크레딧이 있어요. 사람이 많아지거나 오래 켜 두면 유료(월 5달러 정도) 플랜이 필요할 수 있어요. 대시보드의 **Usage** 에서 사용량을 볼 수 있어요.

**빠른 성장(테스트 모드)**: 관리자 계정으로 로그인했을 때만 키우기 탭에 보여요. 닉네임 `admin`, 비밀번호 `1133` (서버가 켜질 때 자동으로 만들어져요. 비밀번호를 바꾸려면 Railway Variables 에 `ADMIN_PASS` 를 넣으세요). 다른 사람은 `admin` 으로 가입할 수 없고, 다른 계정에서는 테스트 모드가 보이지도 켜지지도 않아요. 한 번이라도 켰던 몽글이는 결투장에 **테스트** 표시가 남아요.

**코드를 고치고 싶을 때**: GitHub 저장소에서 파일을 고치거나 새로 올리면(Commit), Railway가 알아서 다시 배포해요. 저장 공간(Volume)에 있는 데이터는 그대로 남아요.

**비밀번호**: 서버에는 비밀번호 원문이 아니라 암호화된 값만 저장돼요. 그래도 다른 사이트와 같은 비밀번호는 쓰지 않도록 친구들에게 알려 주세요. 비밀번호 찾기 기능은 아직 없어요.

## 폴더 구성

| 파일 | 하는 일 |
|---|---|
| `server.js` | 서버. 로그인, 시간 계산, 훈련 판정, 결투장, 배틀을 처리하고 저장해요 |
| `public/core.js` | 게임 규칙(진화 조건, 능력치, 배틀 계산). 서버와 화면이 같은 파일을 써요 |
| `public/index.html`, `app.js`, `style.css` | 게임 화면 |
| `package.json` | 필요한 부품 목록 (Railway가 보고 자동 설치) |

## 게임 규칙 요약

- **시간으로 자라요**: 알 **10분** → 유체 **12시간** → 아성체 **24시간** → 성체 (레벨·경험치는 없어요)
- 알은 **품기** 버튼을 누르고 있는 동안 시간이 10배로 흘러요 (계속 누르고 있으면 1분이면 부화)
- 유체·아성체는 **건강도**(배부름·기분·청결의 평균, 똥 1개마다 청결 −25%)에 따라 성장 속도가 달라요: 80% 이상 1배, 50% 이상 0.5배, 50% 밑이면 멈춤
- 창을 닫아도 서버 시간으로 흘러요. 들어왔을 때 진화할 때가 지났으면 진화 장면부터 보여 줘요. 진화는 한 번에 한 단계만 (장면을 보기 전에는 다음 진화가 일어나지 않아요)
- 성체가 되면 타입·형태·능력치가 고정되고 더 이상 키우거나 돌볼 수 없어요
- 새 알 받기는 성체가 됐을 때만 키우기 탭 아래에 나타나요

**결투장과 랭킹**
- 성체를 결투장에 등록하면 랭킹에 올라가요. **한 계정당 최대 2마리**. 꽉 찼을 때 새 성체를 올리려면 둘 중 하나를 골라 내려요(내린 몽글이의 전적은 사라짐)
- 새 알을 받아도 결투장 몽글이는 그대로 남고, 새 몽글이를 키우는 동안에도 결투장 몽글이로 배틀할 수 있어요
- 2마리면 어느 쪽이 출전할지 골라요. 도전 횟수는 몽글이마다 따로: 등록하면 10번, 최대 10번, 10분마다 1번 회복, 도전 1회에 1번
- 상대 고르기: 다른 유저가 등록한 성체 중 **무작위 3마리**가 나오고, "다른 상대 보기"로 다시 뽑을 수 있어요
- 랭킹은 **랭킹 탭**에서 봐요
- 랭킹: (승 − 패)가 큰 순 → 승이 많은 순 → 승·패가 똑같은 몽글이끼리는 서로 맞붙은 전적(승자승) → 그래도 같거나 맞대결이 없으면 **공동 순위**
- 능력치는 **체력·공격력·방어력·속도** 4가지. 훈련으로 각각 올려요
- **모든 훈련은 1회에 최대 +20**
- **체력 훈련은 줄넘기 게임**: 막대 위 원이 양끝 구역(6칸)에 들어왔을 때 **터치!** 를 누르면 방향이 바뀌고 몽글이가 줄넘기를 해요. 성공할 때마다 원이 1.12배 빨라지고, 구역 밖에서 누르거나 끝을 지나치면 끝나요. 성공(편도) 1번마다 체력 +1 (최대 20)
- **속도 훈련은 폭탄 피하기**: 화면이 세로 3줄로 나뉘고 위에서 폭탄이 한 줄씩(1~2개) 떨어져요. **◀ ▶** 또는 화면 왼쪽·오른쪽 반을 눌러 몽글이를 옆 줄로 옮겨 피해요. 시간이 갈수록 빨라지고, 폭탄에 닿으면 끝나요. 한 줄 피할 때마다 속도 +1 (최대 20)
- 네 훈련 모두 끝나면 화면 가운데에 결과가 2초 뜨고, 누른 시각을 서버가 다시 계산해서 확정해요
- **방어 훈련은 조준점 막기**: 몽글이가 액정에 꽉 차게 커지고, 몸 크기 직사각형의 네 꼭짓점과 정가운데(5곳) 중 한 곳에 조준점이 떠요. 시간 안에 조준점을 누르면 막기 성공. 막을 시간은 1.2초에서 20번째 0.35초까지 줄고, 다음 조준점은 0.2~1초 무작위 뒤에 떠요. 가끔 0.1초 간격 3연속이 나와요. 1번 막을 때마다 방어력 +1 (최대 20). 조준점 밖을 누르거나 시간이 지나면 끝
- **공격 훈련은 묵찌빠**: 오른쪽에 상대 손이 뜨면 아래 **묵·찌·빠** 버튼 중 이기는 손을 내요(까만 말풍선 '지는 손!'이면 지는 손). 낼 시간은 1.2초에서 20번째 0.4초까지 줄어요. 틀리거나 늦으면 끝. 1번 성공마다 공격력 +1 (최대 20)
- 배부를 때 밥을 주면 고기는 놓이지만 고개를 좌우로 돌리며 안 먹어요
- 밥 먹는 연출이나 훈련이 끝날 때까지 다른 버튼은 눌리지 않아요
- 알일 때는 능력치가 없어요. **부화하는 순간** 기본 능력치가 무작위로 정해져요: 체력 50~70, 공격력+방어력+속도 합 30 (각각 최소 5). 여기에 훈련과 단계 보너스(아성체·성체가 될 때)가 더해져요
- 배부름 12시간, 기분 16시간이면 100에서 0이 돼요. 똥은 3시간마다 +1(최대 4)
- 에너지는 3분에 1씩 회복(최대 100), 훈련 1번에 20 (유체~성체 동안 최대 약 41번)
- 빠른 성장(테스트 모드, 관리자 계정만)을 켜면 모든 시간이 60배로 흘러요 (성체까지 약 36분)

**성체 타입 (묵·찌·빠)** — 돌봄으로 쌓인 타입 점수로 정해져요
- 밥 주기 → 묵 +2, 훈련 → 찌 +1, 놀아주기 → 빠 +3 (배부를 때 밥, 기분 최고일 때 놀기는 점수 없음)
- 성체로 진화하는 순간 점수가 가장 높은 타입이 돼요
- 묵은 찌에 강하고 빠에 약해요 · 찌는 빠에 강하고 묵에 약해요 · 빠는 묵에 강하고 찌에 약해요
- 유리하면 주는 피해 **1.15배**, 불리하면 **0.9배**
- 배틀 피해 = 공격력² ÷ (공격력 + 상대 방어력) × 상성 (방어력이 공격력만큼 높으면 피해가 절반)
- **속도**: 속도만큼 행동 게이지가 차서 100마다 행동해요. 속도가 2배면 2번 공격해요. 속도 비율이 높을수록 잘 피하고(최대 25%) 치명타(1.6배, 최대 25%)가 잘 나요
- **타입 기술**(액티브, 공격할 때 20% 확률로 발동, 피해 1.3배): 묵 돌주먹 · 찌 손가락찌르기 · 빠 백열장. 기술도 피할 수 있고 치명타와 겹쳐요
- **성향 기술** (예: 묵 타입 공격형 = 돌주먹 · 쌔게때리기 · 분노)
  - 공격형: 패시브 **분노**(맞을 때마다 공격력 +1%) · 액티브 **쌔게때리기**(공격력 500 이상, 10%: 맞히면 상대가 다음 1번 기절)
  - 방어형: 패시브 **웅크리기**(맞을 때마다 방어력 +1%) · 액티브 **가시세우기**(방어력 500 이상, 10%: 맞을 때 피해를 받지 않고 공격한 쪽이 그대로 받음)
  - 속도형: 패시브 **잔상**(맞을 때마다 회피율 +1%p) · 액티브 **두번때리기**(속도 500 이상, 10%: 곧바로 한 번 더 공격)
  - 패시브로 오른 값은 그 배틀 안에서만 유지돼요. 500은 형태 배율까지 곱한 배틀 수치 기준
- 체력 훈련 1점 = 체력 +3
- 80번 행동해도 끝나지 않으면 남은 체력 비율이 높은 쪽이 이겨요

**모습** — 단계·타입 안에서 무작위
- 유체 3종 중 부화할 때 무작위
- 아성체: 공격·방어·속도 훈련 중 가장 많이 한 쪽(같으면 공격 > 방어 > 속도)으로 **공격 쪽 · 방어 쪽 · 속도 쪽**이 정해지고, 쪽마다 2종 중 무작위. 아성체 동안 공격 쪽 공격력 ×1.15, 방어 쪽 방어력 ×1.15·체력 ×1.05, 속도 쪽 속도 ×1.15
- 성체: 묵 6종, 찌 6종, 빠 4종 중 타입에 맞춰 무작위
- 모습마다 붙은 이름(방울몽, 묵바위 등)은 개발용이라 게임 화면에는 안 나와요. 화면에는 단계·타입·형태만 보여요

**성체 형태** — 공격력과 방어력으로 정해져요 (모습과는 별개)
- 성향: 공격·방어·속도 훈련 중 **가장 많이 한 쪽**으로 **공격형 · 방어형 · 속도형**이 정해져요(같으면 공격 > 방어 > 속도). 타입 3 × 성향 3 = 9가지 조합. 예전 만능형은 속도형으로 바뀌어요
- 속도형 배율: 속도 ×1.3, 방어 ×0.95
- 규칙 숫자는 `public/core.js` 위쪽 `RULES`, `ADV`, `DIS`, `STYLES` 에서 바꿀 수 있어요

## (선택) 내 컴퓨터에서 먼저 돌려 보기

https://nodejs.org 에서 Node.js(LTS)를 설치한 뒤, 이 폴더에서 터미널을 열고:

```
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열면 돼요.
